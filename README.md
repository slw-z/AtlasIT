# Project Insights Hub

Crée un tableau de bord de Business Intelligence et de gouvernance de projets IT moderne et professionnel. L'application doit inclure : un menu latéral de navigation, des cartes de KPIs pour le suivi des portefeuilles et des budgets, des graphiques interactifs de performance analytique, et un espace de discussion IA pour interroger les données du projet.
